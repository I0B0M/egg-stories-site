Egg Stories: privacy and data use

The personal Egg Stories publisher uses Google authorization to identify the connected YouTube channel, upload the owner's videos, verify their processing, cover and metadata, schedule releases, and read video/channel analytics. The implementation requests YouTube access and read-only YouTube Analytics access. It uses these data for the channel automation and performance review described on its homepage.

OAuth credentials, refresh/access tokens, resumable upload sessions, quota state and publisher state are stored in private files on the configured execution host. These files are excluded from the source repository. Media, source/editorial QA, release receipts and collected analytics are saved to the configured project/state locations. The operator controls backups, access, sharing and retention of those records; automatic deletion of all collected data is not implemented.

The renderer uses Modal for configured rendering jobs. The render adapter sends story/runtime files and narration to that worker; it does not send the Google OAuth token file. YouTube uploads and analytics requests go to Google's APIs. The publisher implements no sale of Google user data, advertising profile or third-party login service. Data use must remain limited to the disclosed channel workflow and Google's applicable API data-use policies.

The owner can revoke the app's Google access in the Google Account's third-party connections settings and remove retained project/state files on the execution host. Revoking access does not delete videos already uploaded to YouTube; manage those separately in YouTube Studio. Support uses the contact already displayed on the app's Google consent screen.
